MAX LoveMeter — запуск

1. Установи Python 3.10 или новее.
2. Распакуй папку MAX_LoveMeter.
3. Открой эту папку в VS Code.
4. В терминале выполни:
   py -m pip install -r requirements.txt
5. Запусти:
   py app.py
6. Открой в браузере:
   http://127.0.0.1:5000

Чтобы остановить сайт, нажми Ctrl+C в терминале.

Важно:
- Пока сайт работает только на твоём компьютере.
- Чтобы подруги открывали его по ссылке, сайт нужно отдельно опубликовать в интернете.
- Программа не сохраняет введённые имена и интересы в базу данных.
- Процент — шуточная оценка, а не настоящий прогноз отношений.
